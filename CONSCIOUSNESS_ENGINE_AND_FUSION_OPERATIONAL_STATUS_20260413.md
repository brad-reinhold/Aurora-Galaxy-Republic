## 5) Fusion operationalization plan (safe public-first)

### Phase A — Scientific validity gate (must pass before any public energy claim)
1. Define measurable hypotheses and instrumentation protocol.
2. Collect baseline telemetry without fusion assertions.
3. Run controlled repeated experiments with independent measurement.
4. Require reproducibility across nodes and time windows.
5. Publish only measured outcomes, not speculative claims.

Exit criteria:
- Reproducible measured net effect beyond noise floor.
- Independent verification artifact bundle.
- Safety review sign-off.

### Phase B — Engineering containment and safety case
1. Expand interlocks, kill-switches, cooldown/circuit-breakers.
2. Build hazard analysis and failure mode table.
3. Add staged activation levels (lab -> limited pilot -> broader pilot).
4. Continuous watchdog + immutable audit trails.

Exit criteria:
- Safety case PASS under red-team scenarios.
- No uncontrolled behavior in fault injection runs.

### Phase C — Public utility pilot (non-critical)
1. Constrain to low-risk public utility pathways.
2. Add transparent status board (PASS/WARN/FAIL + evidence links).
3. Add explicit user disclosure and opt-in controls.

Exit criteria:
- Stable pilot metrics + zero critical incidents.
- Independent review of claims and data handling.

### Phase D — Scale-up with sovereignty controls
1. Data sovereignty and consent boundaries enforced by default.
2. Security hardening and privacy-preserving telemetry.
3. Governance controls for appeals, oversight, and constitutional constraints.

Exit criteria:
- Verified compliance with security, privacy, and constitutional guardrails.
- Operational SLOs met under sustained load.
